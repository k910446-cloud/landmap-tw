# 地籍圖 / 使用分區查詢

一個可以隨時打開的地圖 App，套疊內政部國土測繪中心的**開放圖磚**，
用來查地段、非都市土地使用分區、使用地類別，以及點位的各種座標。

手機、平板、電腦的瀏覽器都能用；在手機上可以「加到主畫面」，用起來跟原生 App 一樣。

---

## 怎麼啟動

需要 Python 3.8 以上（Windows 已內建或可從 Microsoft Store 安裝）。

**Windows**：直接按兩下 `啟動.bat`。

**任何系統**（在專案資料夾內開終端機）：

```bash
python start.py
```

瀏覽器會自動開啟 <http://127.0.0.1:8777/>。

### 開機自動啟動（已設定）

「啟動」資料夾裡有一個捷徑 **地籍查詢伺服器.lnk**，指向專案裡的 `背景啟動.vbs`。
電腦一開機就會用 `pythonw.exe` 在背景把伺服器跑起來 —— **不會有黑色終端機視窗**。

- **目前網址**：看專案資料夾裡的 **`目前網址.txt`**，每次啟動都會更新。
  （IP 是 DHCP 取得的，重開機或換網路可能會變，以這個檔案為準。）
- **停止**：按兩下 **`停止伺服器.bat`**（它會讀 `.server.pid` 精準關掉那一個行程，
  不會誤殺其他 Python 程式）。
- **取消開機啟動**：Win+R 輸入 `shell:startup`，把「地籍查詢伺服器」捷徑刪掉即可。
- **手動啟動**：按兩下 `背景啟動.vbs`（背景、無視窗），
  或用 `啟動.bat` / `手機模式（含定位）.bat`（有視窗，看得到訊息）。

> 電腦關機時服務就停了 —— App 是這台電腦在供應的。要真正 24 小時可用，
> 得把 `start.py` 放到一台常開的機器（舊筆電、樹莓派、NAS）或雲端主機上。

### 想用手機查（含 GPS 定位）

**Windows**：按兩下 `手機模式（含定位）.bat`。

**任何系統**：

```bash
python start.py --lan --https
```

手機和電腦要連同一個 Wi-Fi。終端機會印出一行像 `https://192.168.1.23:8777/` 的網址。

`--https` 會用 openssl 自簽一張憑證（存在 `certs/`，只發給 localhost 與你的區網 IP）。
第一次在手機開啟會跳安全警告 —— 選「進階 → 繼續前往」即可，那是你自己電腦上的伺服器。
**瀏覽器只在 https 或 localhost 底下給 GPS 權限**，所以手機要用定位就一定要這個。

裝好之後 Chrome 選單 →「加到主畫面」，Safari 分享 →「加入主畫面」，就有一個圖示可以直接點開。

其他參數：`--port 8080` 換連接埠、`--no-browser` 不自動開瀏覽器、`--lan` 只開放區網不啟用 https。

### 分區與類別怎麼顯示

點一下地圖，「點位」頁會直接顯示兩個 **法定名稱**：

```
鄉下（宜蘭縣壯圍鄉）
  非都市土地使用分區          特定農業區   AA
  非都市土地使用地類別（編定）  農牧用地     EE

市區（臺北市大安森林公園）
  都市計畫使用分區            公園用地     PEA
```

名稱來自政府資料開放平臺這兩份資料（內政部國土管理署，政府資料開放授權條款第 1 版，免費）：

- [非都市土地使用分區圖（112年）](https://data.gov.tw/dataset/169538)
- [非都市土地使用地編定圖（112年）](https://data.gov.tw/dataset/169539)

第一次查某個縣市時，App 會顯示下載按鈕；按下去把該縣市的 SHP 抓到 `data/`
（分區 0.6～14 MB、編定 3～44 MB），之後那個縣市離線可用。
判斷是在本機做點在多邊形內的運算，不會把你的座標送出去。

下方的「圖磚顏色取樣」是輔助，用來跟圖面對照。

## 容積分析（開發面積預估表）

網址 <http://127.0.0.1:8777/far.html>，或從 App 的「容積」分頁開啟。

輸入縣市、段、地號（可多筆），產出建築師事務所格式的開發面積預估表：

| 段落 | 內容 |
|---|---|
| 壹、貳 | 各筆地號的登記面積與合計，標明是登記面積還是圖形面積 |
| 叁 | 使用分區、都市計畫名稱、法定建蔽率與容積率 |
| 肆 | **依基地位置自動套用**適用的容積獎勵法規與上限 |
| 伍 | 允設容積：基準容積＋各項獎勵＋容積移轉，每列附條次 |
| 陸 | 設計樓地板面積 e～m（機電、梯廳、陽台、屋突、地下層） |
| 柒 | 停車檢討（土管一戶一車位，或建築技術規則第59條附表） |
| 捌 | 預估銷售面積、戶數、車位持分、開發係數 |
| 玖 | **法規檢核**：設計值對建築技術規則的免計容積上限 |
| 拾 | 資料來源，以及哪些欄位是設計條件而非法規值 |

可列印成 A4 或匯出 CSV。畫面上橘色代表「這個數字沒有法源依據」。

### 自動套用的法規

「肆」會依縣市、都市／非都市、使用分區、基地面積與臨接道路寬度，
判定哪些法規適用、各自上限多少：

- **危老重建** —— 24 個獎勵項目分組擇一（獎勵辦法明訂不得重複申請）；
  基地規模獎勵與時程獎勵直接由面積與申請日算出。
  兩層上限分開計：一般獎勵 ≤ 基準容積 30%，時程＋規模 ≤ 10% 且不受前者限制。
- **容積移轉** —— 中央辦法只有 30%／40%，依道路寬度分級是各縣市自訂的。
  已逐條查證新竹市（第7條，7.2／10／15 公尺三級）與苗栗縣（第5-1條，
  8／12／15 公尺三級）；其餘縣市顯示中央值並註明尚未查證。
- **都市更新** —— 條例第65條的四種上限，與獎勵辦法第5～12條的項目。
- **綜合設計（開放空間）** —— 先做資格檢核（分區、基地面積、臨路），
  不符合就直接說不適用。
- **非都市土地** —— 由使用地類別查非都市土地使用管制規則第9條，
  自動帶入建蔽率與容積率。
- **沿街步道空間退縮獎勵**（目前只查證苗栗縣）—— 苗栗縣騎樓沿街步道空間
  設置自治條例第6條 △FA = S × I，鼓勵係數商業區 3、其他分區 2；
  輸入臨接計畫道路長度後自動算出 S 與 △FA。
  上限依同條準用都市計畫法臺灣省施行細則第34條之3第1項第2款。
- **獎勵容積總上限** —— 都市計畫法臺灣省施行細則第34條之3：
  非都更地區 ≤ 法定容積 1.2 倍（增額 20%）、都更地區 ≤ 1.5 倍。
  六都不適用（有自己的自治條例）。

### 不能跨區套用

地方法規只在自己的轄區有效，套錯區等於憑空多給容積，而且畫面上看起來
一切正常。所以有四道把關，每一道都有測試（`tests/test_bonuses.py`）：

1. **縣市要對** —— 苗栗縣的自治條例在別的縣市完全不出現，連「參考值」都不給。
2. **地號要查得到** —— 使用者在選單上選「苗栗縣」不構成證明；地號查不到
   就不套用任何地方法規，只留中央法規，並在表上說明原因。
3. **要在都市計畫地區內** —— 非都市土地不適用都市計畫法系的任何獎勵。
4. **分區要單純** —— 基地跨兩種以上使用分區時，鼓勵係數無從判定，
   只說明不給數字。

換一塊地時，上一塊地的勾選會全部歸零 —— 沿用是最隱蔽的跨區套用。

分區名稱的比對也刻意從嚴：曾經用「名稱含『商』字」判定商業區，
結果「科技商務專用區」拿到商業區的係數 3，獎勵憑空多五成。
現在只有叫得出「商業區」或商一～商十才算，其餘取低的係數並提醒人工確認。

### 尚未登錄的地方獎勵

大街廓整體開發、開發時程、來賓車位這類獎勵訂在**個別都市計畫**的土管要點裡，
百分比逐案不同。系統會告訴你「這一項存在、去哪裡查」，但不會把舊案的
百分比當成法規值套進去 —— 查證後用「＋新增獎勵容積」自行填入並註明法源。

### 數字從哪裡來

- **算式**：從 13 份建築師事務所的實際製表反推，再逐案回帶驗算到小數點後兩位
  （`tests/test_far.py`）。機電設備的計算基數要排除非都市計畫法系的
  獎勵，就是這樣回帶出來的。

### 多筆地號合併評估

一次可以輸入多筆地號，跨段也可以（一行寫「段名 地號」）。表上每一筆都是
一列，可以：

- **勾掉不納入** —— 排除的地號仍列在表上並註明理由。
  頭份信義段那份寫「不包括頭份市有地660-1」、尖山段寫「不含河川區29地號」，
  直接讓它消失的話，看表的人沒辦法核對為什麼沒算。
- **改面積** —— 德義段那份寫「218部分」，只納入一部分；
  或謄本與圖資對不起來時人工指定。人工填的面積會標成假設值。
- **跨分區分算** —— 每筆地號的使用分區是各自查出來的。基地跨兩種分區時，
  基準容積 = Σ(各分區面積 × 該分區容積率)，建築面積同理。
  拿第一筆的分區套整塊地，在「商業區帶住宅區」的臨街基地會差很多，
  而且畫面上看起來完全正常。

### 地下層：不一定是全開挖

地下室的面積有三種給法，在表上直接切換：

| 模式 | 算法 | 什麼時候用 |
|---|---|---|
| 基地 × 開挖率 × 層數 | 預設，開挖率可改 | 初步評估 |
| 單層面積 × 層數 | 直接給單層輪廓 | 已有配置圖（竹北家興段那份就是這樣寫） |
| 逐層給面積 | B1、B2、B3 各自填 | B1 因車道與退縮而比 B2 小 |

開挖率是設計條件不是法規值，一律標成假設值。少數縣市的土管有訂上限
（例如新竹市容積移轉審查許可規則第9條的 85%），個案要自行確認。

### 停車：土管優先

建築技術規則第59條第1項寫的是「依都市計畫法令或都市計畫書之規定，
**其未規定者**，依下表規定」——土管有訂就從土管，附表是備位規定。
所以預設走土管的「住宅一戶一車位」，另可加來賓車位（不得出售）與機車位；
土管條次由使用者填，沒填就標成無法源。要用附表也可以切換。

戶數不用坪數倒推 —— 那是「銷售坪 ÷ 每戶坪數」，每戶坪數本身就是猜的，
填錯會得到離譜的戶數。預設改成「地上層數 × 每層戶數」（一樓可另計），
並反推每戶平均銷售坪，超出 12～120 坪就標出來。

### 各家事務所的寫法不同，所以做成可選

同一批參考資料裡，同一個欄位就有好幾種算法，算出來差好幾百平方公尺。
表上直接提供切換，改完立刻看得到差異：

| 欄位 | 寫法 | 出現在 |
|---|---|---|
| 梯廳 | 自我參照 `(e+f) × r ÷ (1−r)` | 上立事務所（舊社段等 10 份）|
| | 直接乘 `(e+f) × r` | 新竹中寮段 |
| 銷售面積分子 | 允設容積 | 舊社段三份（× 1.5，公設比 1/3）|
| | 允設容積＋陽台 | 新竹中寮段 |
| | 允設容積＋機電＋陽台 | — |

預設用上立那套（自我參照梯廳 + 允設容積分子）。
公設比的定義是「公設佔總銷售面積的比例」，分子再把機電、梯廳、陽台
加進去等於把免計容積算兩次 —— 一開始就是這樣寫錯的。
- **法條**：逐條連線全國法規資料庫抓取並複驗，`rules.py` 與 `bonuses.py`
  的每一筆都附法規名稱、條次、版本日期與連結。
- **面積與分區**：各縣市地籍圖與都市計畫使用分區的公開圖服務。

沒有法源的欄位（開挖率、公設比、坪／戶這類設計與市場條件）一律標為橘色，
並在「拾」列成清單。本表為初步評估，實際以主管機關核定為準。

### 兩種資料源型態

`datasets.py` 的 `URBAN_COUNTIES` 支援兩種寫法，要新增縣市加一行就好：

```python
# 一、下載型：一個縣市一到多個 SHP 壓縮檔
'高雄市': [('https://…下載網址', 檔案大小), …],

# 二、即時查詢型：縣市公開的 ArcGIS MapServer，免下載
'臺中市': {'service': 'arcgis', 'url': 'https://…/MapServer/1/query', 'wkid': 102443},
```

欄位命名各縣市都不同，`DATASETS['urban_zone']` 用候選清單吸收差異
（`使用分區`／`ZONENAME`／`ZoningName`／`LUSE`／`LANDUSE`／`NAME`／`ZONE`…）。
**順序有意義**：彰化同時有 `ZONENAME`（名稱）與 `ZONE`（代碼），
而新北的 `ZONE` 存的卻是名稱，所以 `ZONENAME` 必須排在 `ZONE` 前面。

### 還沒進來的縣市

- **新竹縣**：縣府「智慧圖資雲」只有地籍、地價與非都市土地，沒有都市計畫。
  全縣唯一公開成圖服務的是**竹東鎮公所自己架的 GeoServer**，已經接進來
  （「都市計畫」群組裡的三層：使用分區、計畫區範圍、細部計畫），
  但涵蓋範圍就是竹東鎮，出了鎮界是空的。其餘鄉鎮市目前沒有來源 ——
  國土測繪中心的公開圖磚 444 層裡也只有非都市土地那兩層。
- **臺南市**：都發局圖台從測試環境連線逾時，沒能確認。
- **其餘 13 縣市**：都有自己的都市計畫圖台，但地圖服務多半要互動後才載入，
  靜態抓不到服務網址，也沒有共通 API，需一個一個開瀏覽器攔請求。
  data.gov.tw 上還有一則[「請各縣市都市計畫使用分區資料開放」](https://data.gov.tw/suggests/80424)的提案，
  派發給 21 個縣市 —— 全國性的開放本來就不齊。
- **全國一次到位的選項**：向國土管理署城鄉發展分署申請
  「全國土地使用分區圖資介接服務」（付費，115/1/1 起），
  那是付費介接的圖磚，看得到界線與顏色，但點下去沒有名稱。

另外，**查不到非都市分區的點，多半就在都市計畫區內** —— 非都市分區圖涵蓋所有非都市土地，
落在外面的就是都市計畫區或國家公園。App 會直接這樣提示。

「說明」頁有一張**資料涵蓋範圍**表，可以看到每個縣市目前是即時查詢、已下載、還是尚未下載。

| 臺北車站 | 公園段一小段 188 地號，11,485 m²（3,474 坪） |

國土測繪中心的「座標查地號」需要申請介接，但**臺北市、桃園市、臺中市、新竹市、新竹縣、苗栗縣、彰化縣**
把自己的地籍圖以公開 ArcGIS 服務發布，可以直接對座標做點查詢，不需要任何金鑰。

**面積**：服務有面積欄位就用它（那是登記面積）；沒有的縣市（臺中、苗栗）改用回傳的
宗地圖形自己算，換算成二度分帶後用平面公式求積。畫面會標示面積來自「服務欄位」
還是「由圖形計算」。準確度以有面積欄位的縣市對照驗證過：新竹縣自算 800.5 m²
對服務回報 800.0 m²，差 0.06%。

這些圖層只有段名、段碼、地號、面積等圖籍屬性，**沒有所有權人等個資**
（我逐一檢查過每個服務的欄位定義）。

地號在地政系統裡是 8 碼（母號 4 + 子號 4），各縣市有的給格式化好的字串、
有的給 8 碼、有的母子號分欄，App 統一整理成「1165」「47-2」這種標準寫法。

### 在地圖上顯示地號

「圖層」頁的 **「地籍圖（含地號）」** 群組：桃園、臺中、新竹市、彰化、苗栗五個縣市，
打開之後**地號會直接標在地圖上**。這一組走縣市 ArcGIS 的動態出圖（`export`），
圖面本身就帶地號註記，放大到第 16 級以上才出圖（避免一次向對方主機要太多張）。

**新竹縣**在同一組裡，但走的是快取圖磚而不是 `export`：界線一張、地號註記一張，
兩張都開就等於其他縣市的效果。之所以不用 `export`，是因為那台主機的 `export`
每張圖磚要八秒、一個畫面要一分半，而快取圖磚只要 0.1 秒。

「地籍」群組另有苗栗縣的**宗地界線快取圖磚**（載入較快但沒有地號）。

新竹縣的主機還有一個限制：**一次只肯服務一個連線**，同時有第二個就整批回 403。
所以對這台主機的請求（圖磚與查詢）都排成一列一個一個送，被擋到會自動重試 ——
程式在 `web/serial.js` 與 `start.py` 的 `open_url()`。它的查詢端點本身也慢，
一筆固定十幾二十秒，所以點位查詢時會先提示「這個縣市的主機較慢」。

查到地號時，該筆**宗地輪廓會用橘色框畫在地圖上**，一眼就知道命中哪一筆。

### 其他縣市

其餘縣市的宗地地籍圖、座標查地號、地籍屬性查詢，國土測繪中心是以
**申請介接、綁定網域或 IP** 的方式提供（實測 `landmaps.nlsc.gov.tw/S_Maps/wmts/DMAPS`
需要 Referer 綁定才回傳圖磚）；地政司的地籍圖資便民系統另有圖形驗證碼保護。
這個 App 不會去繞過那些機制。

- 申請介接：[國土測繪圖資服務雲](https://maps.nlsc.gov.tw/S09SOA/homePage.action?Language=ZH)
- 正式謄本：[全國地政電子謄本系統](https://clir.land.moi.gov.tw/)

要新增縣市，在 `datasets.py` 的 `CADASTRE_COUNTIES` 加一筆（服務網址 + 欄位對照）即可。

## 定位

右上角的 ◎ 按鈕，或「測繪」頁的定位卡片。

- **持續追蹤**：畫出目前位置、精度圈與方位箭頭，地圖自動跟隨；
  自己拖動地圖就解除跟隨（定位繼續跑），按「重新跟隨」回復。
- **即時讀數**：WGS84 經緯度、度分秒、TWD97 二度分帶、水平精度、高程、方位、速度。
  地圖左下角另有一條精簡 HUD。
- **查詢此處**：用目前位置直接跑地號與使用分區查詢，現場站著就知道腳下是什麼地。
- **軌跡記錄**：走一圈把範圍走出來。每 3 公尺記一點（精度差於 50 公尺的點會略過），
  停止時存成目前專案的一條線，可以看長度、改樣式、匯出 GeoJSON。

位置資料只留在瀏覽器裡 —— 畫在地圖上、算距離、存成軌跡。
只有你按「查詢此處」時，座標才會送到本機的 `start.py` 做圖徵查詢。

> 瀏覽器只在 **https 或 localhost** 底下給 GPS 權限。電腦上用 `127.0.0.1` 沒問題；
> 手機在區網要用定位，請用 `--https` 啟動（見上面「想用手機查」）。

## 在地圖上標地號、看邊長

頂端工具列的 **「地號」** 按鈕（或「圖層」頁最上面的開關）：打開之後，
App 會向該縣市的地籍服務要**目前畫面內所有宗地**，畫出界線並把地號標在每一筆上。
放大到第 18 級以上才會標（再低會一次撈到上千筆，服務單次上限會截斷）。

> 底圖「臺灣通用電子地圖」上的 100號、112號那種數字是**門牌**，不是地號。
> 要看地號請用上面這個功能，或把底圖換成「電子地圖（灰階）」「空白」比較不會混淆。

**點到的那筆宗地**除了橘框標示，還會在每條邊的中點標上**邊長（公尺）**，
面板裡也會列出 L1、L2… 各邊長度與**周長**。可以用面板裡的核取方塊關掉圖上的邊長標示。

邊長依宗地圖形節點計算（TWD97 二度分帶），跟測繪工具同一套算法。
圖形節點與實地界址會有測量誤差，正式尺寸請以地籍圖謄本或鑑界成果為準。

## 測繪與專案

「測繪」頁提供點、線、面、圓四種繪製工具，並即時顯示量測結果。

- **距離與面積**都先把經緯度換算成 TWD97 二度分帶再用平面公式計算，
  跟地政圖資同一套座標系。已用「TM2 上正好 1 公里見方」驗證：
  面積 1,000,000 m² = 100.0000 公頃 = 302,500.00 坪 = 103.1016 甲，周長 4,000 m，完全吻合。
- **單位**同時給 m²／公頃／**坪**／**甲**（1 坪 = 400/121 m²，1 甲 = 2934 坪）。
- 線與面：依序點頂點，按「完成」、按 Enter 或雙擊結束，Esc 取消。
  圓：先點圓心，再點一下決定半徑。
- 每個物件可命名，並調整顏色、線寬、不透明度、填滿程度。
- 物件歸屬於**專案**，可新增／改名／刪除專案，切換專案時地圖只顯示該專案的物件。
- **匯出專案**（JSON，可再匯入）或**匯出 GeoJSON**（可直接丟進 QGIS、Google Earth）。

資料存在瀏覽器的 localStorage，換裝置請用匯出／匯入。

## 資料更新與測試

每一份資料都是某個時間點的快照：法規會修正、實價登錄每季發佈、政府圖資每年換版。
沒有人盯著的話它會安靜地變成過期資料 —— 畫面照樣好好的，數字卻是舊的。

**自動更新**：`.github/workflows/refresh-data.yml` 每月檢查一次，
有變動才重建並提交，沒變動就什麼都不做。實價登錄的原始檔會快取，
只有新的一季需要下載。也可以到 Actions 頁面手動觸發。

**自己檢查**：跑 `檢查資料是否過期.bat`（或 `python check_updates.py`），
它會比對目前收錄的法規修正日期與季別，跟上游現在的版本。

**測試**：跑 `執行測試.bat`（或 `python -m unittest discover -s tests`）。
測的都是純函式 —— 座標換算、面積、地號補零、varint 編解碼、法條數字解析。
這個專案最怕的不是當掉，是安靜地算錯：面積少一位數、地號補零補錯、
座標偏幾百公尺，畫面上都長得很正常。實際上也發生過（「持分移轉」曾被
當成特殊交易排除，把幾乎所有住宅成交都濾掉），所以這些測試不是形式。
