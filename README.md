# 地籍圖 / 使用分區查詢

一個可以隨時打開的地圖 App，套疊內政部國土測繪中心的**開放圖磚**，
用來查地段、非都市土地使用分區、使用地類別，以及點位的各種座標。

手機、平板、電腦的瀏覽器都能用；在手機上可以「加到主畫面」，用起來跟原生 App 一樣。

---

## 怎麼啟動

需要 Python 3.8 以上（Windows 已內建或可從 Microsoft Store 安裝）。

**Windows**：直接按兩下 `啟動.bat`。

**任何系統**（在專案資料夾內開終端機）：

```bash
python start.py
```

瀏覽器會自動開啟 <http://127.0.0.1:8777/>。

### 開機自動啟動（已設定）

「啟動」資料夾裡有一個捷徑 **地籍查詢伺服器.lnk**，指向專案裡的 `背景啟動.vbs`。
電腦一開機就會用 `pythonw.exe` 在背景把伺服器跑起來 —— **不會有黑色終端機視窗**。

- **目前網址**：看專案資料夾裡的 **`目前網址.txt`**，每次啟動都會更新。
  （IP 是 DHCP 取得的，重開機或換網路可能會變，以這個檔案為準。）
- **停止**：按兩下 **`停止伺服器.bat`**（它會讀 `.server.pid` 精準關掉那一個行程，
  不會誤殺其他 Python 程式）。
- **取消開機啟動**：Win+R 輸入 `shell:startup`，把「地籍查詢伺服器」捷徑刪掉即可。
- **手動啟動**：按兩下 `背景啟動.vbs`（背景、無視窗），
  或用 `啟動.bat` / `手機模式（含定位）.bat`（有視窗，看得到訊息）。

> 電腦關機時服務就停了 —— App 是這台電腦在供應的。要真正 24 小時可用，
> 得把 `start.py` 放到一台常開的機器（舊筆電、樹莓派、NAS）或雲端主機上。

### 想用手機查（含 GPS 定位）

**Windows**：按兩下 `手機模式（含定位）.bat`。

**任何系統**：

```bash
python start.py --lan --https
```

手機和電腦要連同一個 Wi-Fi。終端機會印出一行像 `https://192.168.1.23:8777/` 的網址。

`--https` 會用 openssl 自簽一張憑證（存在 `certs/`，只發給 localhost 與你的區網 IP）。
第一次在手機開啟會跳安全警告 —— 選「進階 → 繼續前往」即可，那是你自己電腦上的伺服器。
**瀏覽器只在 https 或 localhost 底下給 GPS 權限**，所以手機要用定位就一定要這個。

裝好之後 Chrome 選單 →「加到主畫面」，Safari 分享 →「加入主畫面」，就有一個圖示可以直接點開。

其他參數：`--port 8080` 換連接埠、`--no-browser` 不自動開瀏覽器、`--lan` 只開放區網不啟用 https。

### 分區與類別怎麼顯示

點一下地圖，「點位」頁會直接顯示兩個 **法定名稱**：

```
鄉下（宜蘭縣壯圍鄉）
  非都市土地使用分區          特定農業區   AA
  非都市土地使用地類別（編定）  農牧用地     EE

市區（臺北市大安森林公園）
  都市計畫使用分區            公園用地     PEA
```

名稱來自政府資料開放平臺這兩份資料（內政部國土管理署，政府資料開放授權條款第 1 版，免費）：

- [非都市土地使用分區圖（112年）](https://data.gov.tw/dataset/169538)
- [非都市土地使用地編定圖（112年）](https://data.gov.tw/dataset/169539)

第一次查某個縣市時，App 會顯示下載按鈕；按下去把該縣市的 SHP 抓到 `data/`
（分區 0.6～14 MB、編定 3～44 MB），之後那個縣市離線可用。
判斷是在本機做點在多邊形內的運算，不會把你的座標送出去。

下方的「圖磚顏色取樣」是輔助，用來跟圖面對照。

### 兩種資料源型態

`datasets.py` 的 `URBAN_COUNTIES` 支援兩種寫法，要新增縣市加一行就好：

```python
# 一、下載型：一個縣市一到多個 SHP 壓縮檔
'高雄市': [('https://…下載網址', 檔案大小), …],

# 二、即時查詢型：縣市公開的 ArcGIS MapServer，免下載
'臺中市': {'service': 'arcgis', 'url': 'https://…/MapServer/1/query', 'wkid': 102443},
```

欄位命名各縣市都不同，`DATASETS['urban_zone']` 用候選清單吸收差異
（`使用分區`／`ZONENAME`／`ZoningName`／`LUSE`／`LANDUSE`／`NAME`／`ZONE`…）。
**順序有意義**：彰化同時有 `ZONENAME`（名稱）與 `ZONE`（代碼），
而新北的 `ZONE` 存的卻是名稱，所以 `ZONENAME` 必須排在 `ZONE` 前面。

### 還沒進來的縣市

- **新竹縣**：縣府「智慧圖資雲」是 token 認證，且以地籍測量為主；
  縣內另一套使用分區查詢系統只涵蓋**竹東鎮**，而且是「地段＋地號」查詢，
  不是座標查詢，接不進本 App 的點查詢模型。
- **臺南市**：都發局圖台從測試環境連線逾時，沒能確認。
- **其餘 13 縣市**：都有自己的都市計畫圖台，但地圖服務多半要互動後才載入，
  靜態抓不到服務網址，也沒有共通 API，需一個一個開瀏覽器攔請求。
  data.gov.tw 上還有一則[「請各縣市都市計畫使用分區資料開放」](https://data.gov.tw/suggests/80424)的提案，
  派發給 21 個縣市 —— 全國性的開放本來就不齊。
- **全國一次到位的選項**：向國土管理署城鄉發展分署申請
  「全國土地使用分區圖資介接服務」（付費，115/1/1 起），

另外，**查不到非都市分區的點，多半就在都市計畫區內** —— 非都市分區圖涵蓋所有非都市土地，

「說明」頁有一張**資料涵蓋範圍**表，可以看到每個縣市目前是即時查詢、已下載、還是尚未下載。

**面積**：服務有面積欄位就用它（那是登記面積）；沒有的縣市（臺中、苗栗）改用回傳的

### 在地圖上顯示地號

「圖層」頁的 **「地籍圖（含地號）」** 群組：桃園、臺中、新竹市、彰化、苗栗五個縣市，
打開之後**地號會直接標在地圖上**。這一組走縣市 ArcGIS 的動態出圖（`export`），
圖面本身就帶地號註記，放大到第 16 級以上才出圖（避免一次向對方主機要太多張）。

「地籍」群組另有新竹縣與苗栗縣的**宗地界線快取圖磚**（載入較快但沒有地號），
以及新竹縣的地號註記圖磚。

查到地號時，該筆**宗地輪廓會用橘色框畫在地圖上**，一眼就知道命中哪一筆。

### 其他縣市

其餘縣市的宗地地籍圖、座標查地號、地籍屬性查詢，國土測繪中心是以
**申請介接、綁定網域或 IP** 的方式提供（實測 `landmaps.nlsc.gov.tw/S_Maps/wmts/DMAPS`
需要 Referer 綁定才回傳圖磚）；地政司的地籍圖資便民系統另有圖形驗證碼保護。
這個 App 不會去繞過那些機制。

- 申請介接：[國土測繪圖資服務雲](https://maps.nlsc.gov.tw/S09SOA/homePage.action?Language=ZH)
- 核准後把地籍圖磚網址加到 App 的**自訂圖層**就會顯示
- 正式謄本：[全國地政電子謄本系統](https://clir.land.moi.gov.tw/)

要新增縣市，在 `datasets.py` 的 `CADASTRE_COUNTIES` 加一筆（服務網址 + 欄位對照）即可。

## 定位

右上角的 ◎ 按鈕，或「測繪」頁的定位卡片。

- **持續追蹤**：畫出目前位置、精度圈與方位箭頭，地圖自動跟隨；
  自己拖動地圖就解除跟隨（定位繼續跑），按「重新跟隨」回復。
- **即時讀數**：WGS84 經緯度、度分秒、TWD97 二度分帶、水平精度、高程、方位、速度。
  地圖左下角另有一條精簡 HUD。
- **查詢此處**：用目前位置直接跑地號與使用分區查詢，現場站著就知道腳下是什麼地。
- **軌跡記錄**：走一圈把範圍走出來。每 3 公尺記一點（精度差於 50 公尺的點會略過），
  停止時存成目前專案的一條線，可以看長度、改樣式、匯出 GeoJSON。

位置資料只留在瀏覽器裡 —— 畫在地圖上、算距離、存成軌跡。
只有你按「查詢此處」時，座標才會送到本機的 `start.py` 做圖徵查詢。

> 瀏覽器只在 **https 或 localhost** 底下給 GPS 權限。電腦上用 `127.0.0.1` 沒問題；
> 手機在區網要用定位，請用 `--https` 啟動（見上面「想用手機查」）。

## 在地圖上標地號、看邊長

頂端工具列的 **「地號」** 按鈕（或「圖層」頁最上面的開關）：打開之後，
App 會向該縣市的地籍服務要**目前畫面內所有宗地**，畫出界線並把地號標在每一筆上。
放大到第 18 級以上才會標（再低會一次撈到上千筆，服務單次上限會截斷）。

> 底圖「臺灣通用電子地圖」上的 100號、112號那種數字是**門牌**，不是地號。
> 要看地號請用上面這個功能，或把底圖換成「電子地圖（灰階）」「空白」比較不會混淆。

**點到的那筆宗地**除了橘框標示，還會在每條邊的中點標上**邊長（公尺）**，
面板裡也會列出 L1、L2… 各邊長度與**周長**。可以用面板裡的核取方塊關掉圖上的邊長標示。

邊長依宗地圖形節點計算（TWD97 二度分帶），跟測繪工具同一套算法。
圖形節點與實地界址會有測量誤差，正式尺寸請以地籍圖謄本或鑑界成果為準。

## 測繪與專案

「測繪」頁提供點、線、面、圓四種繪製工具，並即時顯示量測結果。

- **距離與面積**都先把經緯度換算成 TWD97 二度分帶再用平面公式計算，
  跟地政圖資同一套座標系。已用「TM2 上正好 1 公里見方」驗證：
  面積 1,000,000 m² = 100.0000 公頃 = 302,500.00 坪 = 103.1016 甲，周長 4,000 m，完全吻合。
- **單位**同時給 m²／公頃／**坪**／**甲**（1 坪 = 400/121 m²，1 甲 = 2934 坪）。
- 線與面：依序點頂點，按「完成」、按 Enter 或雙擊結束，Esc 取消。
  圓：先點圓心，再點一下決定半徑。
- 每個物件可命名，並調整顏色、線寬、不透明度、填滿程度。
- 物件歸屬於**專案**，可新增／改名／刪除專案，切換專案時地圖只顯示該專案的物件。
- **匯出專案**（JSON，可再匯入）或**匯出 GeoJSON**（可直接丟進 QGIS、Google Earth）。

資料存在瀏覽器的 localStorage，換裝置請用匯出／匯入。

## 圖層位置校正

不同來源的圖資套疊常有幾公尺的偏差。「圖層」頁最下方可以整體平移所有疊圖圖層，
單位公尺、正值往東／往北，位移量會隨縮放層級自動換算成像素。校正值存在這台裝置上。

---

## 自訂圖層

「圖層」頁最下方可以貼上任何 WMTS／XYZ 圖磚網址（座標系需為 EPSG:3857），
用 `{z}` `{x}` `{y}` 當佔位符。國土測繪中心系列的順序是 `/{z}/{y}/{x}`，
一般 XYZ 圖磚是 `/{z}/{x}/{y}`。設定存在瀏覽器裡，重開仍在。

## 檔案結構

```
landmap-tw/
├─ start.py                 本機伺服器：靜態檔案、/proxy 代理、圖徵查詢 API
├─ geo.py                   純 stdlib 的 Shapefile 解析與點在多邊形內判斷
├─ datasets.py              開放資料集登錄表 ← 要加圖徵圖層改這裡
├─ data/                    下載的縣市圖資（自動建立）
├─ 啟動.bat                 Windows 一鍵啟動（有視窗）
├─ 手機模式（含定位）.bat    開放區網 + https，手機可用 GPS
├─ 背景啟動.vbs             背景啟動、無視窗（開機自動執行的就是這個）
├─ 停止伺服器.bat           讀 .server.pid 停掉伺服器
├─ stop.py                  停止邏輯
├─ 目前網址.txt             每次啟動自動寫入當下網址
├─ certs/                   自簽憑證（--https 時自動產生）
└─ web/
   ├─ index.html            版面
   ├─ app.css               樣式（自動跟隨系統深色模式）
   ├─ app.js                主程式：地圖、查詢、取樣、地段、收藏、圖層校正
   ├─ draw.js               測繪：繪製、距離面積量測、專案管理
   ├─ locate.js             定位：持續追蹤、精度圈、即時座標、軌跡記錄
   ├─ layers.js             圖層目錄 ← 要加圖層改這裡
   ├─ twd97.js              TWD97 / TWD67 二度分帶座標轉換
   ├─ sw.js                 Service worker（離線開啟殼層）
   ├─ manifest.webmanifest  PWA 設定
   ├─ icons/                圖示
   └─ vendor/               Leaflet 1.9.4（已內含，不需連 CDN）
```

`start.py` 的 `/proxy` 只轉送 `*.gov.tw` 與 Nominatim，其他網域一律 403。
它存在的理由有三個：讓 canvas 能取樣圖磚顏色（需要 CORS 標頭）、
在本機快取圖磚減少對政府主機的請求、以及繞過 Python 3.13 對部分政府憑證的
嚴格檢查（僅關閉 `VERIFY_X509_STRICT` 這項附加檢查，憑證鏈與主機名稱仍完整驗證）。
