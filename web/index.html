座標

在手機上會直接開 Google 地圖 App。導航是以這個點為終點。

地號標示

直接向縣市地籍服務要畫面內的宗地，畫出界線並標上地號。 涵蓋臺北、桃園、臺中、新竹市、新竹縣、苗栗、彰化，放大到第 17 級以上才會標。

用實價登錄最近兩年的紀錄，把畫面內每筆地號改標成 該地號的每坪單價中位數，並依價位上色。沒有成交紀錄的地號仍標地號。

注意：底圖「臺灣通用電子地圖」上的 100號、112號那種數字是門牌，不是地號。要看地號請開這個功能， 或把底圖換成「電子地圖（灰階）」或「空白」比較不會混淆。

圖層位置校正

不同來源的圖資可能有套疊誤差。這裡整體平移疊圖圖層，單位公尺， 正值往東／往北。校正值存在這台裝置上。

定位

持續追蹤會畫出目前位置與精度圈，拖動地圖即解除跟隨。 軌跡每 3 公尺記一點，停止時存成目前專案的一條線。 位置只留在這台裝置上；只有你按「查詢此處」時座標才會送到本機伺服器做圖徵查詢。

手機在區網要用定位，請改用 python start.py --lan --https 啟動 —— 瀏覽器只在 https 或 localhost 底下給 GPS 權限。

繪製與量測

面積與距離換算成 TWD97 二度分帶後計算，跟地政圖資同一套座標。 面積同時給 m²／公頃／坪／甲。線與面可按 Enter 或雙擊結束，Esc 取消。

專案

GeoJSON 可直接丟進 QGIS、Google Earth 或其他 GIS 軟體。

這個 App 查得到什麼

  • 非都市土地使用分區（特定農業區、山坡地保育區…）、 使用地類別／編定（農牧用地、乙種建築用地…），以及 都市計畫使用分區（臺北、新北、桃園、新竹市、苗栗、臺中、彰化、高雄）的法定名稱與代碼。 名稱來自政府開放資料的圖徵屬性，不是用顏色猜的；第一次查某縣市會提示下載該縣市圖資， 之後離線可用，座標也不會送出去。
  • 座標查地號：點一下就顯示段名、地號與面積 （臺北、桃園、臺中、新竹市、新竹縣、苗栗、彰化），命中的宗地會用橘框標出來。
  • 地圖上顯示地號：「圖層」頁的「地籍圖（含地號）」群組。
  • 都市計畫圖層：使用分區著色圖與計畫區範圍框。
  • 段籍圖、公有土地地籍圖：地段界線、段名，公有地為宗地層級。 新竹縣與苗栗縣另有宗地界線圖磚。
  • 非都市土地使用分區圖與使用地類別圖圖磚套疊。
  • 國土利用現況調查：實際使用情形，可與法定編定對照。
  • 點位的 WGS84 經緯度、TWD97 二度分帶、TWD67 二度分帶 座標。
  • 該點所屬 縣市／鄉鎮市區／地政事務所／地段／村里。
  • 繪製與量測：點、線、面、圓，距離與面積（m²／公頃／坪／甲）， 物件可命名與設定樣式，依專案分類，可匯出 JSON 或 GeoJSON。
  • 圖層位置校正：修正不同來源圖資的套疊誤差。
  • 定位：持續追蹤、精度圈、即時座標、以目前位置直接查詢、軌跡記錄。

載入中…

「已下載」的縣市離線可用；「即時查詢」走該縣市公開的圖服務， 不佔空間但需要連線。

都市計畫使用分區

已內建 8 個縣市：臺北、新北、桃園、新竹市、苗栗、臺中、彰化、高雄， 直接顯示法定名稱。其中桃園、新竹市、苗栗、臺中、彰化走縣市公開的查詢服務， 連下載都不用；多數還附上建蔽率與容積率，臺中另有上限容積與細部計畫名稱。

新竹縣的分區系統只涵蓋竹東鎮且是地段地號查詢；臺南市圖台連不上； 其餘縣市的平台與格式各自不同，要逐一接。 上面的「資料涵蓋範圍」可以看到目前狀況。

想一次覆蓋全國，可向國土管理署城鄉發展分署申請 「全國土地使用分區圖資介接服務」（付費），把 WMTS 網址貼到「圖層」頁的 付費介接服務；那是圖磚，看得到界線但點不出名稱。

另外：當某點查不到非都市分區時，多半就代表它位於都市計畫區內 ——非都市分區圖涵蓋所有非都市土地，落在外面的就是都市計畫區或國家公園。

地號與地籍圖

座標查地號已可用於 7 個縣市：臺北市、桃園市、臺中市、新竹市、新竹縣、苗栗縣、彰化縣。 這幾個縣市把自己的地籍圖以公開圖服務發布，點一下地圖就會顯示段名、地號， 部分還有面積（同時給坪）。這些圖層只有圖籍屬性，沒有所有權人等個資。

「圖層」頁的「地籍圖（含地號）」群組可以把地號直接標在地圖上 （臺北、桃園、臺中、新竹市、彰化、苗栗）；「地籍」群組另有新竹縣與苗栗縣的 宗地界線快取圖磚，載入較快但沒有地號。

其餘縣市的宗地地籍圖與座標查地號，國土測繪中心是以 申請介接、綁定網域或 IP 的方式提供；地政司的查詢圖台另有圖形驗證碼保護。 這個 App 不會去繞過那些機制。到 國土測繪圖資服務雲 正式謄本請用 全國地政電子謄本系統。

官方查詢入口

  • 地籍圖資網路便民服務系統（內政部地政司）— 查地號、地籍圖
  • 全國土地使用分區資料查詢系統（國土管理署）— 都市計畫／非都市／國家公園分區
  • 國土測繪圖資服務雲（國土測繪中心）
  • 全國地政電子謄本系統 — 正式謄本

免責聲明

本 App 僅套疊政府開放圖磚供參考，不是地籍謄本，也不是土地使用分區證明。 涉及權利、交易、申請許可時，請以地政事務所核發之謄本與 直轄市／縣（市）政府核發之土地使用分區證明為準。
